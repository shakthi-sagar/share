# Development guide

## Prerequisites

- Node.js 22 or newer
- pnpm 10 or newer
- Wrangler authentication only when using remote Cloudflare resources

## Setup

```sh
pnpm install
cp .env.example .env
pnpm config:check
pnpm dev
```

The root command validates configuration, generates Wrangler configuration, builds the static asset
snapshot used by the Worker, and starts the Vite and Wrangler development servers together.

## Configuration workflow

Edit only the root `.env` for active environment values. It is ignored by Git.

```sh
pnpm config:check
pnpm config:sync
```

`config:sync` generates `apps/api-cloudflare/wrangler.generated.jsonc`. That file is ignored and must
not be edited manually. Add new variables to all of these places:

1. `.env.example`
2. validation and normalization in `scripts/config.mjs`
3. the consuming application
4. relevant documentation

Browser-visible variables must use the `SHARE_PUBLIC_` prefix. Vite exposes only that prefix.

## Common commands

| Command | Purpose |
| --- | --- |
| `pnpm dev` | Start the web and API development servers |
| `pnpm config:check` | Validate the active root `.env` |
| `pnpm config:sync` | Generate Wrangler configuration |
| `pnpm biome check .` | Check formatting and lint rules |
| `pnpm check` | Type-check every workspace package |
| `pnpm test` | Run all unit tests |
| `pnpm build` | Build packages and web assets, then perform a Worker dry run |
| `pnpm deploy:cloudflare` | Apply migrations and deploy the production Worker |
| `pnpm smoke:deployment` | Exercise the deployed health, web, CORS, D1, R2, and auth path |

## Making changes

### Protocol or crypto

Read `docs/protocol.md` first. Preserve compatibility unless the change includes a versioning and
migration design. Add tests that prove successful round trips and rejection of tampered ciphertext,
wrong context, invalid lengths, and boundary indices as relevant.

### API

Keep business rules in `@share/server`. Hono routes should parse input, authorize, enforce body
limits, call a service, and translate the result to HTTP. Put Cloudflare-specific persistence in an
adapter.

Any endpoint that returns share data must authorize before touching R2. Avoid response differences
that disclose whether a share ID exists.

### Web

Keep encryption and transport logic in `@share/client`. Components own interaction and rendering.
Preserve relative paths for nested folders and fetch file ciphertext only when the user selects or
downloads that file.

Follow `docs/design-system.md` and `docs/design-decisions.md`. Reuse semantic tokens and established
component patterns. Verify keyboard access, visible focus, complete interaction states, readable
errors, mobile layout, and long filenames.

### New client surfaces

CLI and MCP packages should depend on `@share/client`, `@share/crypto`, and `@share/protocol` as
needed. They must use the same API routes and manifest format. Avoid browser-only types in shared
packages.

## Tests

Tests live next to their owning package under `test` or beside a small pure helper. Prefer tests that
exercise invariants and failure behavior over tests that copy implementation structure.

Before submitting a change:

```sh
pnpm biome check .
pnpm check
pnpm test
pnpm build
```

## Generated and local files

Do not commit:

- `.env` or `.dev.vars`
- `wrangler.generated.jsonc`
- `.wrangler/`
- `dist/`
- coverage or logs

`worker-configuration.d.ts` is generated by Wrangler and excluded from Biome. Regenerate it with the
workspace `types` script when binding types change.
